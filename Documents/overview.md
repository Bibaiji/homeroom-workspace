### v2.3 更新内容

1. **所有「选学生」处统一加搜索建议**：家校沟通、学生成长、纪律登记、作业未交快速添加、座次表（入座/交换）、值日表添加值日生、成绩录入、班委担任学生——全部改为输入框实时搜索（按姓名/学号匹配，点击建议即填入）。成绩录入选中学生还会自动带出已有成绩，避免误覆盖。
2. **座次表点击姓名即可交换座位**：点击已坐学生的座位，弹窗里输入姓名搜索，点击搜索结果立即与对方交换位置（显示对方当前座位如「2排2列」）；点击空位则搜索入座，且自动排除已入座学生。
3. **家长联系去掉跳转、只留复制按钮**：移除短信/拨号会卡顿的 `tel:`/`sms:` 链接，每位家长仅保留「复制号码」按钮（点一下即复制），卡片头部保留「复制通知文案」按钮（粘贴到微信/短信即可）。

5. **去除干扰元素**：左下角「v2.2 · 意式极简版 数据仅存于本机浏览器」角标已删除；点进页面后的「回 WorkBuddy 继续聊」按钮通过链接加 `?fromWbMp=1` 参数隐藏（无副作用）。
6. **整体美观度自主打磨**：优化复制/搜索等交互文案，统一空状态与提示语气，确认全站无 `tel:`/`sms:` 跳转、无遗留角标。

### v2.2 更新内容

1. **「早读考勤」升级为「考勤」，支持一天多场次**：点「场次」按钮可自由添加考勤场次（早读、午休点名、晚自习点名等，可重命名、删除），每场单独记录、互不影响；考勤卡片顶部显示场次标签（带已记录/未记录小圆点），点击切换查看。
2. **标记考勤交互重做（更直观）**：弹窗第一眼就是大按钮「✔ 全员出勤，一键完成」——点了立即保存关闭；有异常时在下方点名标记：每个学生一行，点「请假/缺勤/迟到」即标记（再点一次取消），没点到的默认出勤，顶部实时汇总「已标异常 X 人 · 其余 N 人按出勤」，不再需要逐个看 4 个状态按钮。
3. **性能优化（解决卡顿）**：移除顶栏、弹窗、抽屉的 backdrop-filter 毛玻璃模糊（滚动卡顿主因，改为纯色顶栏+加深遮罩）；全部 `transition:all` 改为具体属性过渡，避免无关属性重排；后台标签页暂停 60 秒定时刷新；考勤点名点击改为单行局部更新，不再整列表重渲（搜索框不再丢焦点）；尊重系统「减少动态效果」设置。
4. **数据兼容**：旧版考勤数据（单场次全量记录）打开自动迁移为多场次格式，不丢历史异常记录。

### v2.1 更新内容

1. **值日表周天数可设置**：总设置新增「一周几天」选项（5 天 / 6 天 / 7 天含周日晚补课），满足高中周日晚上补课场景；值日表页面头部也有「周天数」快捷按钮。
2. **一周第一天可选**：总设置新增「周一为一周第一天」或「周日为一周第一天」选项，课程表列顺序和值日表排布同步切换（周日开头时课程表首列为周日）。
3. **座次表每周自动换座**：新学期每周首次打开时按设定方向自动轮换一次，换座方向可选 6 种：左移一列+后移一排（默认）、仅左移、仅后移、右移一列+前移一排、仅右移、仅前移；采用环形回绕——最后一排向后移变成第一排，最左边一列移到最右边。可在总设置关闭自动换座，也可用「每周换座」按钮手动触发。
4. **指定交换座位**：座次表新增「指定交换」按钮，选择任意两名学生（下拉框显示当前座位如「1排1列」）直接对调位置。
5. **作业布置内容记录**：首页作业收缴升级为「作业布置与收缴」——登记各科今日作业内容（如「课本P52 习题1-5」）+ 未交名单，登记时自动带出该科已布置的作业内容。
6. **作业完成情况汇总**：作业卡片顶部显示汇总条（今日 X 科作业 · 已交齐 Y 科 · 未交共 Z 人次），每科下方显示作业内容与未交学生名单。
7. **考勤名单直接显示**：早读考勤卡片不再只显示数量，请假/缺勤/迟到学生姓名以彩色标签（橙/红/红）直接列出，一目了然。
8. **细节修复**：待办排序错误修复；示例数据空花名册无法重载的问题修复。

### v2.0 更新内容

1. **课程表节次系统全面重构**：每节课自带上课时间（如 08:20-09:05）；节次行可自由增加、删除、上移下移；内置预设环节一键添加：上课、大课间、升旗仪式（可限定周一）、午餐、晚餐、晚自习、查寝，也支持自定义环节（如眼保健操）；特殊环节在课表中以彩色横条带展示。
2. **首页改为「我的今日课程」**：在设置中选定自己的学科（如数学）后，自动聚合显示今天所有班级该学科的课——哪个班、哪间教室、几点钟、当前节次进行中高亮、已上完变淡。原来的两张重复"今日课程"卡片已合并为这一张。
3. **花名册支持删除学生**：删除时自动清理座次表、班委、值日表中的引用（成绩记录保留）。
4. **值日表支持多人增删**：每个时段的值日生可以自由添加、删除成员。
5. **设置新增「一键清空全部数据」**：双重确认后清空本机全部数据（清空后可一键重新加载示例数据）。
6. **全局视觉大改版（意式极简设计系统）**：#F7F8F6 米灰背景、纯白卡片、莫兰迪绿 #5B7065 主色、#2C3E35 深墨绿文本、16px 大圆角、柔和呼吸圆点动画、斑马纹表格、悬停显示操作按钮等，九个页面全部按新设计规范重绘，深色模式同步适配。
7. **旧数据自动迁移**：v1.x 的课表、值日表、单家长数据打开即自动升级，无需手动处理。

### v1.1 更新内容

1. **修复导航空白 bug（根因级修复）**：所有页面（花名册/家长联系/座次表等）首次点击即正常渲染。根因是 JS const 声明不挂载 window，导致导航时渲染函数从未被调用。
2. **工作台首页新增「今日课程」卡片**：直接显示当天课程（节次/时间/科目/老师/教室），支持多班级切换标签，当前节次高亮，已上完的课程自动变淡，每分钟自动刷新。
3. **调休支持**：首页和课程表页均有「调休设置」，可指定今天按周几的课表上（如周六上周一的课），仅当天生效、次日自动恢复，首页今日课程与课表高亮同步更新。

5. **班委职务标记**：花名册表格/卡片视图、家长联系页、座次表座位上自动显示学生担任的班委/课代表/组长职务（绿色角标）。
6. **修复周日高亮 bug**：周日课表列现在能正确高亮与匹配当前节次。
7. **搜索增强**：花名册与家长联系搜索现支持按家长姓名、电话号码搜索。
> 注：自 v2.3 起，家长联系页不再有「一键拨号/发短信」跳转（会卡顿），改为「复制号码 / 复制通知文案」按钮。

### 数据存储与备份

- **本地存储**：所有数据存于浏览器 localStorage（前缀 `hw_`），离线可用
- **一键备份**：设置抽屉或首页按钮 → 导出 `.db.json` 备份文件
- **导入恢复**：通过文件导入恢复，适合跨设备同步（夸克云盘/微信传文件）
- **CSV 导入导出**：花名册、成绩单、课程表均支持 CSV 格式（Excel 可直接打开/保存）

### 跨设备使用方式

**Windows 端**（类似 .exe 体验）：
1. 用 Edge 浏览器打开在线链接
2. 地址栏右侧 → 「安装此站点为应用」
3. 安装后桌面生成独立图标，双击即可像 .exe 一样使用

**Android 端**（类似 .apk 体验）：
1. 用 Chrome 浏览器打开在线链接
2. 菜单 → 「添加到主屏幕」
3. 桌面生成应用图标，点击即可全屏使用

**跨设备数据同步**：
1. A 设备 → 设置 → 导出备份（.db.json）
2. 通过微信/夸克网盘传到 B 设备
3. B 设备 → 设置 → 导入恢复

### 技术架构

- 单文件 HTML，所有 CSS/JS 内联，零外部依赖
- CSS 变量主题系统（浅色/深色模式切换）
- 内联 SVG 图标和图表（柱状图、饼图）
- 响应式设计：PC 侧边栏导航 → 移动端抽屉式菜单
- PWA manifest 支持（可安装到桌面）
- localStorage 数据层 + JSON 备份恢复 + CSV 导入导出
